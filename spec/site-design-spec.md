## 3. מערכת התנועה

חמישה מרכיבים. כל אחד חייב פתרון נסיגה תחת `prefers-reduced-motion: reduce`.

### 3.1 עומק ותאורה (ללא תנועה)

הילה רדיאלית מאחורי אזור הגרף ב-hero, שכבת גרעין על כל העמוד, וסקשנים לסירוגין בין `--base` ל-`--base-deep`.

נסיגה: אין. זה סטטי ממילא.

### 3.2 זרקור עוקב עכבר

בסקשנים `.hero` ו-`.bot` בלבד. שכבה עם
`radial-gradient(400px circle at var(--mx) var(--my), rgba(19,227,230,.07), transparent 65%)`.

JS מעדכן `--mx` ו-`--my` ב-`pointermove`, מווסת דרך `requestAnimationFrame` (עדכון אחד לפריים לכל היותר).

נסיגה: מושבת לגמרי תחת `(hover: none)` ותחת reduced-motion. אין מאזין בכלל במצבים אלה.

### 3.3 גרף הפלאטו קשור לגלילה

- **הקו האפור** (עלייה + פלאטו) נמשך פעם אחת בטעינה, כמו בגרסה 1.
- **הקו הציאן** (הפריצה) קשור להתקדמות הגלילה: `stroke-dashoffset` יורד מ-260 ל-0 ביחס ישר להתקדמות המשתמש דרך ה-hero. הקו נשבר בדיוק כשגוללים אליו.

מימוש מועדף: `animation-timeline: view()` נייטיב, בתוך `@supports (animation-timeline: view())`. נסיגה לדפדפנים ללא תמיכה: `IntersectionObserver` שמפעיל מאזין scroll מווסת ב-rAF, ומחשב progress מ-0 ל-1.

נסיגה תחת reduced-motion: שני הקווים מוצגים מלאים מיד, ללא קשר לגלילה.

### 3.4 מספרים רצים

חל על: ארבעת ערכי סקשן השיטה, ומספרי רצועת הנתונים.

- טריגר: `IntersectionObserver` ב-40% נראות, פעם אחת בלבד לכל אלמנט.
- משך 900ms, האטה `easeOutExpo`.
- טווחים (למשל `1.6–2.2`) — שני המספרים רצים במקביל לאותו משך.
- מספר העשרוניות נשמר כפי שהוא ביעד.
- `aria-live` לא נדרש. ערך היעד חייב להיות בטקסט ב-HTML מראש, וה-JS רק מנפיש אותו — כדי שללא JS המספר הנכון עדיין מוצג.

נסיגה: הערך הסופי מוצג מיד.

### 3.5 כפתורים במשקל וליטוף אור בכרטיסים

- **כפתורים**: חל על כפתורי הפעולה בלבד (`.btn-primary` ו-`.btn-ghost`), לא על כפתורי ממשק כמו סגירת הצ'אט או ההמבורגר. משיכה מגנטית עדינה — הכפתור זז עד 4px לכיוון הסמן כשהוא מעליו, וחוזר בקפיץ ביציאה.
- **כרטיסי מסלולים**: ב-hover, אור בצבע ההדגשה נע לאורך המסגרת (conic-gradient ממוסך ל-border). לא הרמה ולא צל.

נסיגה: שניהם מושבתים; נשאר רק שינוי צבע מסגרת.

### 3.6 מעברי עמוד

```css
@view-transition { navigation: auto; }
```
הלוגו בניווט מקבל `view-transition-name: brand` כך שהוא נשאר יציב במעבר בין עמודים. דפדפנים ללא תמיכה מקבלים ניווט רגיל, ללא שבירה.

## 5. עמוד הטכניקה

### 5.1 מקור נתונים

`app/exercises.json`, נגזר ידנית מ-`knowledge/exercise-technique.md`. עשרה תרגילים. סכימה:

```json
{
  "id": "back-squat",
  "name": "סקוואט אחורי",
  "nameEn": "Back Squat",
  "pattern": "squat",
  "video": null,
  "summary": "משפט אחד על מטרת התרגיל",
  "cues": ["רמז ביצוע", "רמז ביצוע"],
  "mistakes": ["טעות נפוצה", "טעות נפוצה"],
  "evidence": "המשפט המחקרי מתוך מאגר הידע"
}
```

`pattern` הוא אחד מ: `squat` / `hinge` / `push` / `pull`.

**התוכן חייב להילקח מילולית מ-`exercise-technique.md`.** אין להמציא רמזי ביצוע או ממצאים מחקריים חדשים.

### 5.2 מבנה

Master–detail. רשימת התרגילים מימין, פרטי התרגיל משמאל.

- מסנני תבנית תנועה מעל הרשימה: הכל / סקוואט / כפיפת מותניים / דחיפה / משיכה.
- בחירת תרגיל מציגה: מסגרת הווידאו, תקציר, רמזי ביצוע, טעויות נפוצות, והערת הביסוס המחקרי.
- במובייל: הרשימה ראשונה; בחירה חושפת את הפרטים וגוללת אליהם.

### 5.3 כתובת לכל תרגיל

כל תרגיל ניתן לקישור ישיר: `technique.html#back-squat`.

- בטעינה, אם יש hash — נבחר התרגיל המתאים.
- בבחירה — `history.pushState`, כדי שכפתור "אחורה" יעבוד.
- `popstate` מסנכרן את הבחירה בחזרה.
- hash לא מוכר — נבחר התרגיל הראשון, בלי שגיאה.

### 5.4 סרטונים שיגיעו בהמשך

זו דרישה מפורשת של גיא: הסרטונים ייוצרו בנפרד ובהמשך, והעמוד צריך לחכות להם בלי להיראות שבור.

- `video: null` → מסגרת 16:9 מעוצבת עם הודעה שהסרטון בהכנה. **כל תוכן הטכניקה מוצג במלואו.**
- `video: "<url>"` → הסרטון מוצג במקום המסגרת, בלי שום שינוי קוד.
- העמוד חייב להיראות שלם גם עם אפס סרטונים וגם עם עשרה.

## 6. הבוט מפנה לסרטוני טכניקה

כששאלה נוגעת לתרגיל ספציפי, תשובת הבוט מלווה בקישור ישיר לאותו תרגיל.

חוזה התגובה מתרחב:
```json
{ "reply": "טקסט התשובה", "link": { "href": "technique.html#back-squat", "label": "לצפייה בתרגיל" } }
```

`link` אופציונלי.

**אבטחה — חובה:** טקסט התשובה נכתב תמיד דרך `textContent`, לעולם לא `innerHTML`. הקישור נבנה כאלמנט `<a>` נפרד, ו-`href` נבדק שהוא מתחיל ב-`technique.html#` לפני הרינדור. כל ערך אחר — הקישור לא מוצג.

## 7. מחשבון חלבון

ממוקם בתוך סקשן השיטה, צמוד לשורת הנתון 1.6–2.2.

- קלט: משקל גוף בק"ג.
- פלט מיידי בהקלדה: "בין X ל-Y גרם חלבון ביום", כאשר X = משקל × 1.6 ו-Y = משקל × 2.2, מעוגלים למספר שלם.
- טווח קלט תקף: 30–300 ק"ג — אותו טווח שמוגדר במאגר הידע לבקרת קלט. מחוץ לטווח: הודעה שמבקשת ערך סביר, ללא תוצאה.
- לקוח בלבד. אין שליחה לשרת, אין שמירה.

# נספח א׳ — פרטי ביצוע

הנספח נוסף אחרי מעבר ביקורת על האפיון. כל סעיף כאן נכתב כדי למנוע נקודה שבה המבצע יצטרך לנחש או להמציא.

## א.1 מצב התוכן לעמוד הטכניקה

סקירה של `knowledge/exercise-technique.md` מול הסכימה בסעיף 5.1 חשפה פער: להיפ תראסט לא היה שום תוכן על אופן הביצוע (הערך היחיד עליו עסק בהשוואת הפעלת שרירים), ולשלושה תרגילים נוספים לא היו טעויות נפוצות מתועדות.

**הפער נסגר ב-2026-09-21.** נוספו חמישה זוגות שאלה-תשובה מבוססי מחקר: טכניקת ביצוע וטעויות להיפ תראסט, וטעויות נפוצות לדדליפט, ללחיצת כתפיים ולמתח/פולי עליון. בנוסף, בארבעה תרגילים שבהם הטעויות היו כתובות בתוך תשובת הטכניקה (חתירה, RDL, לחיצת רגליים, לאנג') הן פוצלו לזוגות שאלה-תשובה עצמאיים, ללא הוספת תוכן חדש.

## א.3 סכימת הווידאו

שדה `video` הוא `null` או אובייקט:

```json
"video": { "src": "https://res.cloudinary.com/.../exercise.mp4", "poster": "https://res.cloudinary.com/.../exercise.jpg" }
```

הסרטונים יאוחסנו ב-Cloudinary (כבר בשימוש בפרויקט ללוגו). רינדור: `<video controls preload="metadata" poster="...">`. בלי `autoplay` ובלי `loop`. אם אין `poster` — הפריים הראשון ישמש, ואסור שהמסגרת תיראה שחורה וריקה.

## א.4 מה משתנה ב-`index.html` הקיים

העמוד קיים ועובד. אלה השינויים הנדרשים, ולא כתיבה מחדש:

6. הוספת מחשבון החלבון לשורת 1.6–2.2 בסקשן השיטה.
7. הוספת כפתור המבורגר ופאנל ניווט למובייל.
8. עטיפת ערכי הנתונים כך שאנימציית המספרים תוכל לתפוס אותם, עם ערך היעד כבר בטקסט.
